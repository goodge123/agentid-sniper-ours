# AgentID Sniper

Agent ID 专属铸造监控与自动铸造工具。
跑在自己的 Linux 服务器上，逐块扫 BSC 发现新的 Agent ID 专属项目，
免费的自动打、收费的只出分析，执行统一走币安 Agentic Wallet（baw），
本程序不碰私钥。

## 发现

- 逐块扫描新部署合约：代码（含代理追到的逻辑合约）必须含 Agent ID 登记合约
  才算 Agent ID 专属
- 热度发现：同一合约短时间内被多个钱包调用，其中有 Agent ID 钱包且代码
  含登记合约的，纳入追踪
- 学习：已追踪合约被 Agent ID 钱包成功调用的 calldata 记下来，
  换成自己的地址后作为候选打法探测（transfer/approve 类选择器在黑名单里不学不试）
- 扫块取数失败的区块记入缺口表，每 30 秒补扫，不永久漏检

## 免费：自动打

- 用自己钱包地址 eth_call 实测：零金额能过才算真免费（门禁、额度一并实测）
- 时机：进度 ≥60% 才打；读不到进度要 100 个以上 Agent ID 钱包在打且未开池；
  未到门槛进追踪，临近门槛（≥45%）转 15 秒快速检查
- 合约审核门（A 档）：执行前定位逻辑合约、拉 Sourcify 已验证源码扫红旗——
  硬红旗（selfdestruct / delegatecall / tx.origin / 逻辑可升级 /
  owner 可拉黑改税暂停）拦下不打并报告；软提示（owner 可增发等）照打标注；
  未验证照打并标注「源码未验证」
- gas 拦截：执行前估算 >600,000 拦下报告
- baw 预览模拟把关：必须真能拿到东西、无授权变化、不扣预期外资产；
  钱包 BNB ≥0.0005 才送；超时结果不明不重打
- 能连打的最多 10 份（每份计数，打满或复探 revert 才停）；每钱包每天上限 100 笔
- 失败分两种：预演显示会扣资产/无到账/有授权变化 = 硬失败，不再试；
  预演请求或送出环节的临时失败 = 2 分钟后重试，连续 3 次才放弃

## 收费：只监控 + 出分析，永不自动打

- 持续追踪进度、已售/总量、参与的 Agent ID 钱包数
- 到门槛（进度 ≥60%，或读不到进度但 100+ 钱包在打）出一次分析：
  类型（BNB 报价 / USDT 份额 / NFT 单价）、链上实读单价、
  按每钱包每项目 10U 上限算最多份数与总成本、参与钱包数、
  部署者与黑名单、连发项目数、有无退款保本、是否已开池、
  合约权限提醒 + 源码审核结果
- 结论三档：不打（黑名单 / 1 份超 10U / 无退款 / 审核硬红旗）、
  观望（参与 <20 / 留权限 / 已开池 / 审核软提示）、可以打
- 没有退款函数的直接报一次「不打」，不静默跳过
- 要打：主聊天确认份数 → 预览报总成本与每份到账 → 再确认才执行

## 持仓与卖出

- 自动止盈（真卖）：到 3 倍卖出回本 + 50% 利润对应的量（付费仓按
  1.5÷当前倍数 算比例，免费仓卖一半），只触发一次；从高点（≥2 倍）
  回落 40% 全部卖出，连续两次确认才动手防假摔；市值不到 0.3U 不卖
- 免费币的倍数基准：开池后头 3 次读价取中位数锁定，不拿单次乱价当基准
- 卖出登记前先核对链上代币余额确实减少，baw 报成功但余额没变的不算卖出
- 5/10/20 倍和池子流动性告急只发信号
- TG 手动卖出两步确认：先预告，120 秒内回「确认卖」才执行；
  同名币禁止按名卖，必须给合约地址
- TG 可查：余额、持仓

## 安全口径

- 没有自动更新通道：版本人工维护
- 没有文件指令通道：本地文件改不出交易
- baw 调用不走 shell，防参数注入
- RPC 多节点轮替 + 坏节点冷却（全冷却时至少试最早解禁的一个，不假死）
- 状态文件原子写入 + 上一份完好状态留 .bak；主文件损坏时自动从 .bak 恢复，
  损坏原件改名留证，不静默清空
- 配置与会话明文存放：服务器单用户、目录 700、config 600
- 离线自测（不发交易）：`node watch.mjs --selftest`

## 部署（Linux 服务器）

- Node 20+；baw 钉版：`npm i -g @binance/agentic-wallet@1.11.0`
- `config.json` 从 `config.example.json` 复制后填：钱包、推送、自己的 RPC 节点
- 登录：`node login.mjs 1`，用币安 App 打开链接确认，复核钱包地址无误
- 常驻：`agentid-sniper.service`（systemd，Restart=always）
